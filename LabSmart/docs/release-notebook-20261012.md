# 2026-10-12 师生工作流简化版

版本标识：`notebook-20261012`。在线入口：`http://172.18.21.142:3180/`。

## 日常使用

- 学生首页显示自己的实验记录，可搜索、按课题筛选，以标题、日期、可选课题新建。
- 实验详情优先展示正文；原始附件继续使用 eLabFTW 上传、权限和修订能力。参数、辅助检查与低频操作可展开。
- 记录可通过“导师意见与送审”直接送审，不必先运行自动识别。写入权限、登录和 CSRF 检查保留。
- 导师默认查看团队记录；待办默认只显示分配给自己的当前审核。管理员可查看团队待审，历史另列。
- 审核以实验标题显示，一份审核流显示一个任务，退回或拒绝时提示填写具体意见。
- 缺失数值显示“未测量”，没有原始附件时不显示“已上传”。
