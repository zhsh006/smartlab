# 实验现场记录与导师审核：修订要求

来源：2026-10-12 用户反馈。当前简化版降低了页面复杂度，但空白正文仍要求学生自行组织文字、插图，且不同学生的记录格式不一致。新的目标是减少现场输入与事后整理，同时提高审核效率和操作记录的可追溯性。

此文档记录改版要求。基础实现已部署为 `bench-20261012`；实际范围与验证情况见 `release-bench-20261012.md`。模板目前为五类实验的共用基础模板，尚未建立各课题自定义 SOP 版本管理。

## 学生记录

1. 从课题选择实验模板及其版本，创建带唯一编号的实验记录。自由正文用于补充说明。
2. 从已有样本、分组、试剂批次与仪器记录中选择，带入已知信息。模板中的计划条件与操作者确认的实际条件分开保存；默认值不表示已经执行。
3. 页面按实际实验阶段展开，当前阶段只展示必要输入。关键操作支持一键确认、记录实际参数、添加异常说明及拍照。
4. 图片和文件直接关联当前实验及对应步骤，保留原文件；学生无需在正文中调整图片排版。已有结果表可按明确的字段映射导入，映射与数值需确认。
5. 从实际填写、确认的内容生成统一的记录视图及可打印版本。未记录的事项明确显示缺失，不自动生成“已完成”事实。
6. 中途可保存草稿或请求指导；正式提交审核按实验类型检查必要信息与原始证据，辅助算法不构成必经关卡。

## 操作记录

- 保存操作者、确认的实际操作时间、服务器接收时间、步骤、实际参数与对应证据。
- 延迟录入显示补录标记，区分发生时间与录入时间。登录身份与表单中声明的实际操作者分别记录。
- 修改保留原值、新值、修改者、修改时间和必要的修改说明。确认步骤与审核反馈应有可查看的历史。
- 在线确认只表示用户提交了这项记录，不能单凭一次点击证明物理操作已经发生；现场照片、仪器原始文件及纸质操作单构成相应证据。
- 保留纸质路径：按模板生成带编号和二维码的操作单，实验台旁手写，拍照或扫描关联回同一条电子记录。纸质原件与电子整理结果均可查阅。

## 导师审核

- 每个实验使用一致的版式：目的与分组、关键实际条件、步骤记录、原始证据、结果、学生结论。
- 首屏突出缺失项、记录的异常、补录标记及与上次提交相比的更改；明确区分学生记录与系统辅助提示。
- 原图和原始表可从对应步骤或结果直接打开。意见关联具体步骤或字段，学生可直接定位补充。
- 在统一记录视图中完成通过、退回与反馈，避免要求导师从自由正文中寻找关键信息。

## 可复用与待补足

已有代码提供实验类型模板、样本及材料选择、附件、普通记录修订与更改日志、审核和带二维码的 PDF 导出。应优先复用。

现场步骤记录、结构化字段修订历史、按步骤关联证据、统一导师阅读视图及提交快照已实现。旧完整参数表保留为折叠入口。导师意见目前关联整次提交，尚未实现逐字段批注；记录发生时间由实际操作者声明，服务器保存录入时间，不能仅凭在线确认证明物理操作发生。
