# SmartLab 本机 WB 记录页减负改动与验证

2026-10-14。对应用户已同意的这一批：常规步骤直接确认，改条件只填变化项，异常／照片选填。实际部署为 C 盘项目的 Docker 实例：<https://localhost:3159/>。

代码位置：[LabSmart](C:/项目汇总/AGI项目/smartlab/LabSmart)。这是 WB 日常记录的一批改动，不代表整套 V3 验收已通过。

**学生实际需要做的动作**

| 情况 | 现在的操作 | 保留的信息 |
|---|---|---|
| 开始本次实验 | 确定一次样本／批次和分组 | 后续各步骤沿用，无需重复输入 |
| 已有方案或已填草稿，条件齐全 | 看摘要，点一次完成 | 服务端带入已选条件，明确确认后才作为实际值 |
| 改一个条件 | 点“改了条件”，选中该项，只出现一个输入框 | 其他条件、批次关联、附件保持原值 |
| 缺少关键值 | 只展开缺少的项 | 不猜默认值，不把未确定的信息记为已执行 |
| 有异常／补照片 | 勾选异常，说明选填；上传后自动关联本步 | 补照片或说明不会撤销已确认操作或已完成状态 |
| 完成本次操作 | 直接确认完成 | 不要求填写结论、生成报告或提交导师；分析可后补 |

操作者和保存时间默认自动记录；补录、纸质转录及其他操作者放在折叠入口。实验背景、方案与实际对照、修改历史保留在“完整档案”。结构化记录仍然保留。

**实际操作验证**

使用已有学生账号，在一个明确标为“非真实实验”的演示批次中验证了以下路径：

1. 样本和分组只填写一次。
2. 上样量 20 μg / lane、胶浓度 10% 来自已选方案，直接确认完成并进入下一步。
3. 单独把上样量改成 30 μg / lane，胶浓度保持 10%；草稿保存、重登和刷新均保留该值。
4. 一抗和稀释比例已选时，只补缺少的孵育条件。没有重复填写已知条件。
5. 完成本次操作，全程没有填写结果／结论，也没有提交导师。
6. 完成后回到显影步骤，勾选异常，上传合成 CSV；自动关联到本步，实际条件与实验完成状态保持确认。

演示批次：[操作演示：WB 轻记录](https://localhost:3159/smartlab-record.php?id=14)。所有新增演示记录和上传文件均是合成测试数据。

记录语义测试使用数据库事务，结束后回滚，验证了：读取不会写入记录；自动保存不会确认默认值；未知关键值拒绝确认；单项修改不会覆盖其他字段；显式清空不会被方案值填回；附件归属校验；草稿／方案并发冲突拒绝；旧提交和执行时参考值不受后续更改影响；补充附件保留确认状态；完成操作不强制报告。

部署与数据检查结果：

- 6 个应用源文件与运行容器的字节一致，应用和数据库容器健康。
- 改动前 14 条记录及历史行、10 条上传元数据均保持原样。
- 原备份中的 19 个文件逐一比较，字节未改变。
- 本次合成上传的文件字节与 SHA-256 均一致，并关联到已确认步骤；整个实验仍为已完成。
- 1366 × 768 桌面视图：条件已知时，当前步骤可见输入框为 0，主要按钮位于首屏内。
- 390 × 844 手机视图：主要按钮固定在底部；触控高度超过 44 px，页面没有横向溢出。
- 选择一个改动条件时，可见字段只有该项；缺少一个孵育条件时，可见字段只有孵育条件。
